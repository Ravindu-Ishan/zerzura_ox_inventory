z-inventory — reskin, round 6 (refined)

Structure is unchanged from v6 and deliberately so: one connected frame (full-height left column, full-height right column, full-width action bar) with the centre left clear for the ped; the left column is still Appearance as its own card, then a second card holding categories, search, capacity and the grid as one continuous "browse your inventory" unit. This pass is craft only — alignment, rhythm, hierarchy and real item art in place of the three-letter placeholder boxes.

  • Real filled item glyphs replace the "PST / H2O / BRG" text tiles
  • One 10px gutter everywhere — appearance tiles now sit on the same 6-column grid as the slots
  • Category row rebuilt as the guide's own .tab segment strip
  • Segmented capacity bar with slot counts; sticky Backpack section header
  • Accent pulled back to four uses: active category, selected slot, capacity fill, primary keybind
  • Slot counts corrected to the real config (50 player / 41 sedan trunk)
  • Character name moved to the Appearance card's own header (was sitting above the inventory card instead)
  • Only Backpack scrolls now — Pockets stays fully visible always; Backpack scrolls internally if it doesn't fit (e.g. smaller laptop screens)

What changed since v4

1

Appearance now has a heading

Same label style as "Pockets"/"Backpack" below it - the equipped-items strip no longer floats without a name.

2

Categories moved under Appearance

Both now live in the left column instead of a separate top bar, so the whole "who am I / what am I carrying" story reads top-to-bottom in one place.

3

Search: sticky under categories

Pinned right below the category row, above the scrolling grid - the same placement TabLayout already uses for search fields elsewhere in this project (outside the scroll area, under the tabs).

4

No more top bar

With categories and search relocated, there was nothing left to justify a full-width top bar - removing it gives the ped clear space from the very top of the screen down.
