Design draft v6

z-inventory — reskin, round 6

Appearance and Categories were both rows of similar square icon tiles separated only by a hairline, so they read as one confusing blob - and their different tile counts (6 vs 5) made it worse. Fixed by actually applying the theme guide's own core rule: a gapped stack of separate flat blocks, not sections divided by internal rules inside one panel. The left column is now three distinct blocks - Appearance, Categories, and the search/capacity/ grid body - with a real gap between each, so unrelated counts stop looking like a mismatch.

  • Appearance is now its own panel block
  • Categories is now its own panel block, separated by a real gap - not a hairline
  • Search + capacity + grid form the third block (they're genuinely one continuous unit)
  • Mismatched tile counts (6 appearance slots vs 5 categories) no longer reads as an error

What changed since v4

1

Appearance now has a heading

Same label style as "Pockets"/"Backpack" below it - the equipped-items strip no longer floats without a name.

2

Categories moved under Appearance

Both now live in the left column instead of a separate top bar, so the whole "who am I / what am I carrying" story reads top-to-bottom in one place.

3

Search: sticky under categories

Pinned right below the category row, above the scrolling grid - the same placement TabLayout already uses for search fields elsewhere in this project (outside the scroll area, under the tabs).

4

No more top bar

With categories and search relocated, there was nothing left to justify a full-width top bar - removing it gives the ped clear space from the very top of the screen down.
